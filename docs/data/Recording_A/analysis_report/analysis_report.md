## 受試者本次表現

本次為單次騎乘的描述性動作分析，涵蓋十四條肌電通道與同側阻力訊號。整體而言，各肌肉在踩踏週期內的活化形狀重複性尚可，但並非所有部位都一致。左脛前肌的逐圈活化型態在本次紀錄中重複性最低，其次為右脛前肌與右腓腸肌；這三條肌肉在同一踩踏週期中的啟動時機與峰值位置較常出現偏移，值得優先回看。右股外側肌則呈現少數時段活化明顯高於其平常水準的波動，提示該肌肉在特定阻力或姿勢條件下被額外徵召。左右兩側的中位踩踏頻率在本段紀錄中大致一致，未見明顯的單側節律脫落。

## 優先修正線索

- **左脛前肌**是本次最需要回看的部位。其逐圈活化形狀與峰值時機的穩定度低於全部肌肉平均，建議先固定阻力與踏頻，觀察每圈啟動與峰值是否趨於集中，以排除電極位移、皮膚阻抗或足部固定鬆動等非動作因素。
- **右脛前肌與右腓腸肌**的逐圈穩定度亦低於平均，且與左脛前肌同屬踝關節動作鏈。建議同步回看這三條肌肉，判斷不一致是單一部位現象，還是同一動作鏈在特定阻力區段一起改變。
- **右股外側肌**的活化波動幅度最大，少數時段明顯高於其平常水準。可對照當時的阻力變化、踏頻與骨盆或膝部姿勢，確認該波動是否與特定負荷區段或姿勢調整相關。
- 下次量測應維持相同電極位置、皮膚處理、座高與足部固定方式，減少非動作因素造成的振幅差異，使逐圈比較更具可比性。

## 左右策略

本次紀錄中，股直肌的左右中位 RMS 差異最大，右側偏高。這是本次量測內的相對活化不對稱，不等同校正後的左右出力差。可能的解讀方向包括：右側股直肌在該段負荷中被較多徵召、左側在相同阻力下採用了不同的股四頭肌內部分工（例如更多依賴股內側肌或股外側肌），或電極位置與皮膚阻抗造成的量測偏移。

建議下次量測時：
- 比較股直肌左右曲線的峰值時機，確認右側偏高是否持續存在，還是僅出現在特定阻力區段。
- 同時觀察股內側肌與股外側肌的左右比值，判斷是整組股四頭肌的分配差異，還是單一肌肉的局部現象。
- 若需判定真正的左右出力差，需補做 MVC 基準並搭配校正過的扭力或功率量測，僅憑本次 RMS 比值無法下此結論。

## 阻力與節律

同時間點的肌電彙整包絡與同側阻力呈現中等程度的共同升降，左右兩側皆為 available 狀態。此結果僅描述兩訊號在時間軸上的共變，不能視為某條肌肉產生阻力的比例，也不能推導因果關係。

踩踏節律方面，左右中位頻率在本段紀錄中大致相同，且有效間隔數接近，未見單側明顯脫拍。然而，右股外側肌的活化波動提示：在特定阻力或節奏微調時段，該肌肉可能被額外徵召以穩定膝關節或調整骨盆。建議下次量測時以固定阻力區段（例如每三十秒遞增一檔）搭配固定踏頻，觀察各肌肉活化是否隨阻力階梯式改變，而非在連續變負荷中混雜節奏與姿勢因素。

同步方面，本次 EMG 與阻力訊號的對齊為估算訊號相位，並非共同硬體觸發；右側偏好相位與左側參考存在差異，肌肉至力量的延遲可能仍殘留。因此，零時滯的共變描述應保守解讀，不宜直接對應為「肌肉在該瞬間產生該阻力」。
